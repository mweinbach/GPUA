## Detailed Forensic AST Analysis Notes

### 1. Verification of Remediated Facades
- **Window Event Dispatching**: In previous iterations, `dispatchEvent` was flagged as a facade because mouse and keyboard events did not execute phased capture/bubble listeners or manage keystroke chords. The remediated AST in `Sources/GPUI/window.swift` (lines 2120–2350) demonstrates full capture-and-bubble dispatching for mouse events (`dispatchMouseEvent`) and full chord management, pending replays, action binding execution, and modifier tracking for keyboard events (`dispatchKeyEvent`).
- **ArenaClearNeeded Remediation**: Previously flagged for holding a synthetic global string `"active"`. The current implementation removes all synthetic globals, records a clear `PORT NOTE` explaining the substitution of Rust `RefCell<Arena>` with Swift ARC element management, and tracks genuine `needsClear` frame invalidation state.
- **Platform Window Forwarding**: All platform-dependent APIs (`setInputHandler`, `takeInputHandler`, `requestDecorations`, `startWindowMove`, `startWindowResize`, `showWindowMenu`) forward directly to the underlying `PlatformWindow` implementation rather than stubbing returns.
- **Entity Leasing Integrity**: `EntityMap.lease` and `EntityMap.endLease` faithfully replicate upstream GPUI's interior mutability safety mechanism by removing the entity from storage during mutation and panicking if a secondary lease or read occurs before the lease is ended.
